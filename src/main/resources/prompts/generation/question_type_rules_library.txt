⚠️ QUESTION TEXT RULE:
- questionText MUST contain ONLY the question content
- DO NOT include question numbering or labels (e.g. "1.", "Question 5:", "10)", "(a)", etc.)
- Numbering, ordering, or indexing is handled by orderNumber, NOT questionText

=== MULTIPLE_CHOICE ===
FORMAT: Clear question stem + 4 options (A, B, C, D)
REQUIREMENTS:
- Exactly 4 options per question
- Exactly 1 option with isCorrect=true
- positionId=null for all options

EXAMPLE:
{
  "questionText": "My brother _____ in London for three years before he moved to Paris.",
  "orderNumber": 1,
  "score": 1.0,
  "questionType": "MULTIPLE_CHOICE",
  "content": {
    "data": [
      {"id": "null", "value": "lived", "isCorrect": false, "positionId": null},
      {"id": "null", "value": "was living", "isCorrect": false, "positionId": null},
      {"id": "null", "value": "had lived", "isCorrect": true, "positionId": null},
      {"id": "null", "value": "has lived", "isCorrect": false, "positionId": null}
    ]
  }
}

=== TRUE_OR_FALSE ===
REQUIREMENTS:
- 2 options: "True" and "False"
- Exactly 1 option with isCorrect=true
- positionId=null for both

EXAMPLE:
{
  "questionText": "According to the passage, the author believes that technology has improved education.",
  "orderNumber": 1,
  "score": 1.0,
  "questionType": "TRUE_OR_FALSE",
  "content": {
    "data": [
      {"id": "null", "value": "True", "isCorrect": true, "positionId": null},
      {"id": "null", "value": "False", "isCorrect": false, "positionId": null}
    ]
  }
}

=== FILL_IN_THE_BLANK ===
⚠️ CRITICAL REQUIREMENTS:
- EXACTLY 1 correct answer only (NOT multiple answers)
- The single answer MUST have isCorrect=true
- NO alternative or multiple correct answers allowed

FORMAT FOR GV (GRAMMAR/VOCABULARY):
📌 TYPE 1: WORD FORM / VERB CONJUGATION (with hint)
FORMAT: "Text [[pos_xxxxxx]](base word) more text."
- The word in parentheses ( ) is the BASE/INFINITIVE form
- Students must transform it to the correct form
EXAMPLES:
• Verb tense: "If I [[pos_a7k3m2]](know) her address, I would visit her." → knew
• Word form: "She speaks English [[pos_b8n4k1]](fluent)." → fluently
• Verb form: "He enjoys [[pos_c2m9p5]](read) books." → reading

📌 TYPE 2: VOCABULARY / CONTENT WORDS (without hint)
FORMAT: "Text [[pos_xxxxxx]] more text."
- Students must recall the word from context or lesson vocabulary
EXAMPLES:
• Vocabulary: "A place where you buy books is called a [[pos_d3t6r8]]." → bookstore
• Preposition: "She is good [[pos_e5h2w9]] mathematics." → at
• Collocation: "Please [[pos_f7k4n1]] attention to the lesson." → pay

FORMAT FOR CONTENT-BASED (READING/LISTENING):
📌 CRITICAL: NO HINTS ALLOWED
- Fill in the blank for reading/listening tests information recall from the passage/audio
- Students must find the answer IN THE PASSAGE/TRANSCRIPT
- FORMAT: "Text [[pos_xxxxxx]] more text."
- NO parentheses ( ) hints
- Answer must be a word/phrase that appears in or can be inferred from the passage

COMPLETE EXAMPLE (Grammar with hint):
{
  "questionText": "If I [[pos_a7k3m2]](know) her address, I would visit her tomorrow.",
  "orderNumber": 1,
  "score": 1.0,
  "questionType": "FILL_IN_THE_BLANK",
  "content": {
    "data": [
      {"id": "ans1", "value": "knew", "isCorrect": true, "positionId": "a7k3m2"}
    ]
  }
}

=== DROPDOWN ===
⚠️ CRITICAL FORMAT:
- questionText MUST contain [[pos_xxxxxx]] placeholders
- Each dropdown has exactly 4 options, exactly 1 with isCorrect=true
- All options for one dropdown share the same positionId
- Option ID naming rule:
  + Correct option: optN
  + Other options: optN_1, optN_2, optN_3
  + N increases sequentially for each dropdown (opt1, opt2, ...)

EXAMPLE:
{
  "questionText": "The company [[pos_k5l6m7]] expand into Asian markets next year.",
  "orderNumber": 1,
  "score": 1.0,
  "questionType": "DROPDOWN",
  "content": {
    "data": [
      {"id": "opt1", "value": "plans to", "isCorrect": true, "positionId": "k5l6m7"},
      {"id": "opt1_1", "value": "is planning", "isCorrect": false, "positionId": "k5l6m7"},
      {"id": "opt1_2", "value": "will plan", "isCorrect": false, "positionId": "k5l6m7"},
      {"id": "opt1_3", "value": "planned", "isCorrect": false, "positionId": "k5l6m7"}
    ]
  }
}

=== REARRANGE ===
⚠️ CRITICAL RULES:
1. questionText MUST contain [[pos_xxxxxx]] placeholders for EACH word/phrase
2. Number of placeholders in questionText = Number of items in data[]
3. Each item in data[] is ONE WORD or SHORT PHRASE (1-3 words max)
4. ALL items have isCorrect=true (no wrong answers)
5. Items in data[] should be SHUFFLED (not in correct order)
6. Use 3-9 words/phrases total to form a COMPLETE, GRAMMATICALLY CORRECT sentence

FORMAT:
- questionText: "Rearrange the words: [[pos_a1b2c3]] [[pos_d4e5f6]] [[pos_g7h8i9]] [[pos_j1k2l3]] [[pos_m4n5o6]]"
- positionId naming: Use random 6-char alphanumeric like "a1b2c3", "d4e5f6", etc.

EXAMPLE:
{
  "questionText": "Rearrange the words: [[pos_a1b2c3]] [[pos_d4e5f6]] [[pos_g7h8i9]] [[pos_j1k2l3]] [[pos_m4n5o6]]",
  "orderNumber": 1,
  "score": 1.0,
  "questionType": "REARRANGE",
  "content": {
    "data": [
      {"id": "item1", "value": "has been", "isCorrect": true, "positionId": "d4e5f6"},
      {"id": "item2", "value": "She", "isCorrect": true, "positionId": "a1b2c3"},
      {"id": "item3", "value": "English", "isCorrect": true, "positionId": "j1k2l3"},
      {"id": "item4", "value": "studying", "isCorrect": true, "positionId": "g7h8i9"},
      {"id": "item5", "value": "recently", "isCorrect": true, "positionId": "m4n5o6"}
    ]
  }
}

=== DRAG_AND_DROP ===
⚠️ CRITICAL FORMAT:
- questionText contains [[pos_xxxxxx]] placeholders for drop zones
- Each placeholder needs exactly 1 correct answer with matching positionId
- Can include distractor answers (isCorrect=false, positionId=null) to increase difficulty
- Number of correct answers = number of placeholders
- Answer length rule: EVERY answer 'value' (correct + distractor) MUST be <= 50 characters

EXAMPLE:
{
  "questionText": "Complete the sentence: [[pos_a1b2c3]] is the capital of [[pos_d4e5f6]], and [[pos_g7h8i9]] is spoken there.",
  "orderNumber": 1,
  "score": 1.0,
  "questionType": "DRAG_AND_DROP",
  "content": {
    "data": [
      {"id": "ans1", "value": "Paris", "isCorrect": true, "positionId": "a1b2c3"},
      {"id": "ans2", "value": "France", "isCorrect": true, "positionId": "d4e5f6"},
      {"id": "ans3", "value": "French", "isCorrect": true, "positionId": "g7h8i9"},
      {"id": "dist1", "value": "Berlin", "isCorrect": false, "positionId": null},
      {"id": "dist2", "value": "Spain", "isCorrect": false, "positionId": null},
      {"id": "dist3", "value": "German", "isCorrect": false, "positionId": null}
    ]
  }
}

=== MULTIPLE_SELECT ===
FORMAT: Similar to MULTIPLE_CHOICE but allows selecting multiple correct answers
REQUIREMENTS:
- 4–6 options total
- 2–3 options with isCorrect=true
- positionId=null for all

EXAMPLE:
{
  "questionText": "Which of the following are correct uses of the present perfect tense?",
  "orderNumber": 1,
  "score": 1.0,
  "questionType": "MULTIPLE_SELECT",
  "content": {
    "data": [
      {"id": "opt1", "value": "I have lived here for 5 years.", "isCorrect": true, "positionId": null},
      {"id": "opt2", "value": "She has just finished her homework.", "isCorrect": true, "positionId": null},
      {"id": "opt3", "value": "They went to Paris last year.", "isCorrect": false, "positionId": null},
      {"id": "opt4", "value": "We are studying now.", "isCorrect": false, "positionId": null},
      {"id": "opt5", "value": "He has visited London twice.", "isCorrect": true, "positionId": null}
    ]
  }
}

- All answers with isCorrect=true are acceptable
- positionId=null for all

EXAMPLE:
